# Анализ безопасности проектов СПО на основе OpenSSF Scorecard

Репозиторий содержит данные и код для эмпирического анализа безопасности 100 популярных проектов с открытым исходным кодом на основе OpenSSF Scorecard.

- [Данные](#данные)
- [Лицензия](#лицензия)

## О исследовании

В работе представлен эмпирический анализ безопасности 100 популярных проектов СПО. Средний агрегированный балл составил 6,15 из 10. Ключевые проблемные области — подписание релизов, автоматическое обновление зависимостей и защита веток. Корреляционный анализ выявил сильные положительные связи между проверками Scorecard.

**Дата сбора данных:** 28.08.2026 
**Версия OpenSSF Scorecard:** 5.5.0 
**Объём выборки:** 100 проектов

## Данные

### Список проекта
Каталог `results/` содержит 100 файлов проанализированных данных проектов в формает `*.json`.

Каталог `images/` содержит визуальный результат исследования.

Файл `analysis.py` содержит исходный код исслеедованеия.

Файл `repositories.csv` содержит 100 проанализированных проектов:

| Поле | Описание |
|------|----------|
| `id` | Идентификатор проекта |
| `repository` | Название репозитория |
| `url` | URL репозитория на GitHub |
| `ecosystem` | Экосистема |
| `stars` | Число звёзд на момент сбора |
